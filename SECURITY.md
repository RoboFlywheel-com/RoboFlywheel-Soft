# Security policy

## Reporting a vulnerability

Please do not open public issues for security reports. Contact the maintainers
through the GitHub Security Advisories page of this repository ("Report a
vulnerability"). We will acknowledge receipt within 5 working days and aim to
provide an assessment within 30 days.

## Scope

This repository contains research code, small synthetic fixtures, and archived
analysis data. It does not ship credentials, model weights, or production
datasets. If you believe any committed file contains sensitive material
(credentials, personal data, internal endpoints), please report it through the
same channel.

## Supported versions

Only the latest state of the default branch receives fixes.
